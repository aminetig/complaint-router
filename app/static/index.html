Complaint Router

Une réclamation client arrive : le modèle choisit l'équipe qui doit la traiter. S'il n'est pas assez sûr, il la confie à un conseiller plutôt que de se tromper. Le modèle lit des réclamations en anglais.

Exemples :

    MiniLM affiné en PyTorch sur 10 800 vraies réclamations, quantifié en 8 bits et servi par ONNX Runtime. Documentation de l'API · Code source
